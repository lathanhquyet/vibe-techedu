## 💻 Hướng Dẫn Cài Đặt và Chạy Thử (Installation & Setup)

Giảng viên và các bạn có thể chạy thử ứng dụng dưới máy cục bộ (Local) theo các bước sau:

### 1. Yêu cầu hệ thống
*   Đã cài đặt [Node.js](https://nodejs.org) (Phiên bản v18 trở lên)
*   Đã cài đặt Git.

### 2. Các bước triển khai

```bash
# Bước 1: Clone (Tải) repository này về máy
git clone <Dán_đường_dẫn_Github_vào_đây>

# Bước 2: Di chuyển vào thư mục dự án
cd tên-thư-mục-đồ-án

# Bước 3: Cài đặt các thư viện phụ thuộc (Dependencies)
npm install

# Bước 4: Khởi chạy ứng dụng ở chế độ nhà phát triển (Development)
npm run start
```
*Sau khi chạy lệnh trên, ứng dụng sẽ hoạt động tại đường dẫn: `http://localhost:3000`*
